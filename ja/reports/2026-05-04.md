# 週刊 LLM Observability 市場調査レポート
**日付**: 2026-05-04 | **モデル**: google/gemini-3.1-pro-preview

## 1. AI コメント

### 製品ハイライト

- **LangSmith**: LangChain エコシステム向けに深く統合されたエージェントの Tracing と Eval を引き続き提供しており、包括的なネストされたスパンの可視化をネイティブにサポートしています。
- **Arize Phoenix**: 新しい TanStack AI Instrumentation による auto-instrumentation を強化し、Streaming および非 Streaming のチャットコールの両方をキャプチャすることで、フレームワークのサポートを拡大しました。
- **Braintrust**: 厳格な AI 支援によるプロンプト最適化とカスタム Scorer ルーティングを通じて、複雑な Eval ワークフローとデータセット管理を標準化します。
- **Langfuse**: 今週、重要な Tracing、プロンプト、Eval データを分離するための Dedicated Cloud Regions を導入し、エンタープライズのデータ主権とコンプライアンスへの対応を強化しました。
- **W&B Weave**: 強力な Dashboard 分析とネイティブなマルチモーダル Tracing を提供し、従来のモデルライフサイクル管理環境とシームレスに統合します。
- **MLflow**: 今週、一連の重要なアップデートをリリースしました。新しい Trace Graph View、AI 駆動の失敗検知（Detect Issues）、OTEL 向けの GenAI Semantic Conventions、および Gateway Budget Policies により、Observability とコスト管理を強化しています。

### 市場トレンド

LLM Observability 市場では、エンタープライズ向けのきめ細かな制御と、エージェントの深い視覚的デバッグの優先順位がますます高まっています。これは、新しいコスト管理のための Gateway ポリシーや、複雑なマルチターンフロー向けの専門的な Trace Graph View の登場に裏付けられています。

## 2. 最新アップデート

### [Arize Phoenix](https://arize.com/docs/phoenix/release-notes)
- **TanStack AI Tracing** (2026-05-01) — @arizeai/openinference-tanstack-ai 0.1.0+ で利用可能。TanStack AI 向けの新しい OpenInference ミドルウェアは、chat() コールの AGENT、LLM、TOOL スパンを発行します。これは、あらゆる TanStack AI プロバイダーアダプターにわたる Streaming、非 Streaming、およびツールループのフローをカバーします。

### [Langfuse](https://langfuse.com/changelog)
- **Langfuse Cloud Japan** (7日前) — 東京に新しい専用クラウドリージョンを開設し、Tracing、プロンプト、Eval データを日本国内に保持できるようになりました。

### [MLflow](https://mlflow.org/releases)
- **Automatic Issue Detection** (2026年4月7日) — Tracing テーブルの新しい「Detect Issues」ボタンは、AI を使用して、選択した Tracing 内の正確性、安全性、パフォーマンスのカテゴリにわたる品質問題を自動的に特定し、調査のために問題を関連する Tracing にリンクします。
- **Gateway Budget Alerts & Limits** (2026年4月7日) — AI Gateway 向けに設定可能な新しい予算ポリシー。時間枠ごとの支出制限、アラート、コストの自動ブロック、および支出と通知を追跡するための UI を備えています。
- **Trace Graph View** (2026年4月7日) — 複雑なマルチエージェントシステムのデバッグのために、多階層の Tracing 階層と親子スパン関係を可視化する新しいインタラクティブなグラフビュー。
- **Native OpenTelemetry GenAI Convention Support** (2026年4月7日) — MLFLOW_ENABLE_OTEL_GENAI_SEMCONV を有効にして OTLP 経由で Tracing をエクスポートする際、OpenTelemetry GenAI Semantic Conventions をネイティブサポートし、GenAI メタデータを保持します。
- **OpenCode Tracing Integration** (2026年4月7日) — ターミナルベースの AI コーディングアシスタントからのコード実行フローを追跡・分析するための、新しい OpenCode CLI Tracing 統合。
